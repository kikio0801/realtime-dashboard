# 📊 데이터 관리 (Data Management)

본 프로젝트는 **Supabase**를 연동하여 실시간 데이터를 관리합니다. 단순히 정적인 정보를 저장하는 것을 넘어, 다음과 같은 고도화된 방식을 적용합니다.

### 1. Realtime DB
Supabase의 실시간 구성을 통해 환자의 바이탈 상태 변화를 클라이언트에 즉각적으로 반영합니다. 데이터베이스의 변경 사항을 별도의 폴링(Polling) 없이 실시간 스트림으로 수신하여 UI를 업데이트합니다.

### 2. 가상 역사 데이터 생성 (Random Walk)
Pandas를 활용하여 단순 난수가 아닌, 실제 의료 상황과 추세(Trend)를 반영한 임상적 역사 데이터(Random Walk 모델)를 생성합니다.
- **추세 반영**: 환자의 상태가 서서히 좋아지거나 악화되는 흐름을 모방합니다.
- **데이터 적재**: 생성된 정밀 데이터를 Supabase에 일괄 적재하여 실감 나는 포트폴리오 데이터를 구성합니다.

### 3. Analytics 모듈
`analytics/pandas_logic.py`에서 Pandas DataFrame을 활용하여 고도의 데이터 분석을 수행합니다.
- **통계적 추론**: 수집된 바이탈 데이터를 기반으로 환자의 건강 지표를 분석합니다.
- **미래 추세 예측 (Forecasting)**: 시계열 분석을 통해 향후 위험 수치 도달 가능성을 선제적으로 예측하는 로직을 수행합니다.
