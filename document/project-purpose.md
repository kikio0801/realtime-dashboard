# 🚀 프로젝트 목적 상세 가이드

## 1. 환자 중심 모니터링
병실 내 환자들의 상태를 실시간으로 파악하여 담당 간호사의 효율적인 관리를 지원합니다.

## 2. 업무 효율 극대화
빠르고 안정적인 데이터 통신과 직관적인 UI/UX를 통해 의료 현장의 피로도를 낮춥니다.

## 3. 데이터 흐름 검증
단순 기능 구현을 넘어 Next.js - FastAPI - Pandas 간의 유기적인 데이터 흐름을 실험하고 검증합니다.

## 4. 시스템 통합 사례
헬스케어 데이터의 특성을 반영하여 Supabase와 Pandas를 연동한 최적의 데이터 파이프라인을 구축했습니다.
